# つづくラボの道具箱

YouTubeチャンネル「[つづくラボ](https://www.youtube.com/@tsuzukulab)」の動画で紹介した、続けるための道具。

| 道具 | 中身 |
|---|---|
| [66日チェック](66days/) | 習慣が身につくまでの66日を、1日1タップで記録。数えるのは連続じゃなく合計。相棒が一言かける |

- 記録は使う人の端末（ブラウザ）の中にだけ保存されます。サーバー・ログイン・アクセス解析はありません
- 一度開けば、電波がなくても使えます
- 習慣になるまでの日数は人によって大きくちがいます（研究では18日〜254日）。66日は目安です
